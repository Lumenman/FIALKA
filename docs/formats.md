# Форматы файлов

Все файлы в **UTF-8**. Обе реализации читают одни и те же файлы: расхождение
в разборе ловится сверкой (`reference/crosscheck.py`).

Комментарий начинается с `;` и идёт до конца строки.

## Ключ дня — `keys/*.txt`

Повторяет перфокарту. Правило разбора одно: **строка с `=` — заголовок,
строка без — очередной ряд карты**.

```
set  = 6K              ; комплект дисков
card = identity        ; identity | builtin | 30 чисел

Ж Е Б А И   Г Д К В З  ; 1 обода по слотам
Ь Г П У Ц   Ф Ш О Ь Ы  ; 2 кольца
И Д Б В А   З Е К Г Ж  ; 3 сердечники по слотам
2 1 2 1 2   1 1 1 1 2  ; 4 сторона сердечника
Д Б Е Н К   Ц Ы Ф Б К  ; 5 смещение сердечника
```

Значения — буквы алфавита или числа `1..30`; разбивка на две группы по пять
только для читаемости. Ряды 1 и 3 обязаны быть перестановками `1..10`, ряд 4 —
только 1 или 2. Кривой ряд отвергается: он дал бы правдоподобный, но неверный
шифртекст и ничем себя не выдал.

Необязательный **шестой ряд** задаёт начальную установку по умолчанию. Если
его нет, она равна ряду 1 — так же, как выставляет симулятор при загрузке
карты. Настоящая начальная установка приходит ключом `--pos`.

`card` — перфокарта картоприёмника: `identity` (без перестановки), `builtin`
(зашитая в симулятор) или 30 чисел через пробел.

## Комплект дисков — `data/wheels-*.ini`

```ini
[set]
id      = 6K
country = CZ

[wheel1]
wiring = 15 11 5 25 22 16 14 9 17 30 6 27 2 28 13 19 23 18 1 26 12 10 3 29 8 7 20 24 21 4
pins   = 1 2 3 5 7 11 13 14 16 17 19 20 22 23 24 25 27 29 30
```

`wiring` — проводка сердечника, перестановка `1..30`. `pins` — номера
контактов обода, на которых стоит штифт блокировки.

Комплект выбирается строкой `set` в ключе: `set = 6K` ищет `wheels-6K.ini`
рядом с файлом машины. **`id` внутри файла обязан совпасть с именем файла** —
иначе переименованный файл молча оказался бы другим комплектом. Свой комплект
заводится файлом `wheels-МОЙ.ini` с `id = МОЙ`; кода это не требует.

## Машина — `data/machine-M125-3.ini`

```ini
[machine]
alphabet      = АБВГДЕЖЗИКЛМНОПРСТУФХЦЧШЩЫЬЮЯЙ
space_contact = 30      ; пробел делит контакт с последней буквой
probe_even    = 16      ; позиции щупов блокировки
probe_odd     = 19

[entry]
wiring = ...            ; входной диск

[card]
builtin = ...           ; перфокарта, зашитая в симулятор

[print]
upper      = 5 8 - 3 Ж , БК + Й N % . 4 ° 9 7 Ъ 6 2 ЦФ 0 : " 1 = Ф / Э \s ~
shift_up   = 20         ; ЦФ — регистр цифр, клавиша Ф
shift_down = 7          ; БК — регистр букв, клавиша Ж

[keyboard.30]
wiring = ...            ; 0 означает «клавиша отключена»

[reflector.30]
coding       = ...      ; 0 означает «контакт мёртвый»
decoding     = ...
alt_coding   = ...      ; куда мёртвый контакт возвращает сигнал
alt_decoding = ...
```

Секции `keyboard.N` и `reflector.N` есть для N = 10, 26 и 30 — по числу живых
контактов, которое задаёт NumLock. Программа читает только 10 и 30: таблицы на
26 в бинарнике есть, но включать их нечему, см. [mechanism.md](mechanism.md).
Таблицы извлечены из `deco/M125v5_16eng.exe` скриптом
`reference/extract_tables.py`.

Секция `[print]` — верхний ряд печатающей головки, по токену на контакт
1..30. Она не извлечена из бинарника, а прочитана с клавиатуры симулятора и
сверена с рисунком головки в мануале (гл. 3.4.8): в самом exe кириллица лежит
пятью одинаковыми копиями алфавита, без цифр. Два токена особые: `~` — знака
нет, `\s` — точка с запятой, её съедает формат INI. `shift_up` и `shift_down`
— контакты ЦФ и БК; печати они не дают, но шифруются как обычные знаки.

## Подготовка текста — `data/prepare.ini`

```ini
[replace]
Ё = Е
Й = И
. = ТЧК
, = ЗПТ
```

Применяется только по ключу `--prepare` и только к открытому тексту. Ключами
не могут быть `;` и `=` — их съедает формат INI.

**Таблица в мануале не приведена**: `Fialka_200.pdf` даёт только принцип
(гл. 3.2.1), а конкретные коды — наше соглашение по телеграфной практике.
Правится без пересборки, файл читается при каждом запуске.

Заменяется только то, что в выбранном режиме набрать нельзя: в смешанном
цифры, пунктуация и Ъ, Э, Й идут на машину как есть, и таблица для них не
срабатывает.

Цифр в таблице нет намеренно: у М-125-3 для них есть свои режимы, а запись
прописью — соглашение конкретной сети связи, а не свойство машины. Готовый
набор замен лежит в файле закомментированным.
