# Fialka

Эмулятор советской шифровальной машины «Фиалка» М-125.

## Состояние

Механизм машины полностью восстановлен из оконного симулятора
`deco/M125v5_16eng.exe` (Delphi, 2014), сверен с заводским описанием
`Fialka_200.pdf` и **подтверждён экспериментально**: обе реализации
воспроизводят `demo/en.txt` из `demo/de.txt` знак в знак, 24 из 24.

```bash
cd pascal && fpc -O2 fialka.pas && ./fialka --selftest
cd reference && python fialka.py --selftest
python crosscheck.py 300        # обе реализации на случайных ключах
```

## Что где

| путь | что это |
|---|---|
| `pascal/fialka.pas` | **рабочая реализация** на Free Pascal |
| `reference/` | эталонная модель на Python — оракул и сверялка `crosscheck.py` |
| `data/` | машина и комплекты дисков, общие для обеих реализаций |
| `keys/` | ключи дня в формате перфокарты |
| `deco/` | оконный симулятор, его `M125.INI` и скриншот с ключом |
| `demo/` | пара открытый/шифрованный текст и перфокарта ключа 16.08.26 |
| `xml/` | описания машин и комплектов дисков (Cryptomuseum) |
| `The Fialka Challenge/` | задача с mysterytwister.org |
| `Fialka_200.pdf` | Reuvers & Simons, детальное описание машины |
| `fialka.c`, `main*.c` | ранняя попытка на Си, механизм воспроизводит неточно |

## Как пользоваться

```bash
fialka -e -k ../keys/kt16_08_26.txt --pos "П Р К Л М   П О Х Ж Е" msg.txt
fialka -d -k ../keys/kt16_08_26.txt --pos "П Р К Л М   П О Х Ж Е" cipher.txt
```

Ключ дня — файл в формате перфокарты, комплект дисков выбирается его строкой
`set = 6K`. Начальная установка (`--pos`) — ключ сообщения, в оригинале
одноразовый и передаваемый вместе с шифртекстом. Всё в UTF-8.

Разбор расхождений ранней реализации с оригиналом — в документе по механизму,
раздел «Расхождения с существующим кодом на Си».

## Ключевое об алгоритме

- 10 дисков по 30 контактов, соседние вращаются встречно, две независимые
  цепочки с накопительной штифтовой блокировкой; ведущие слоты — 9 и 2.
- Обод и сердечник — разные сущности: обод даёт штифты, сердечник — проводку,
  и в слот они ставятся независимо. Сердечник можно перевернуть:
  `W₂(x) = −W₁⁻¹(−x)`.
- Рефлектор **не инволюция**: одна неподвижная точка и один 3-цикл, поэтому
  буква может зашифроваться сама в себя, а зашифрование и расшифрование
  используют разные таблицы.
- Часть контактов рефлектора не выпускает сигнал, а **возвращает его в барабан
  на новый круг** — машина не однопроходная.
- Алфавит — ровно 30 знаков, пробела в нём нет: пробел делит контакт с буквой
  **Й**. При зашифровании пробел печатается как Й, при расшифровании наоборот.

## Трасса

`--log ФАЙЛ` пишет по строке на каждый узел прохождения знака:

```
--- знак 1: П = контакт 15
  поз     7  6  2  1  9  4  5 10  3  8   щупы -##..###.-
  kb     15>24
  круг 1 вниз   card 24>24  entry 24>29  диски 10:3 9:19 ... 1:26  refl 26>30
  круг 1 вверх  рефлектор >30  диски 1:19 2:15 ... 10:13  entry' 13>12  card' 12>12  kb' 12>20
  =      контакт 20 = Ф
  шаг    вперёд 9,7       назад 2           поз  7  5  2  1  9  4  6 10  4  8
```

Позиции дисков, штифты под щупами (`-` — слот не опрашивается) и **номер
круга** по барабану: когда контакт рефлектора мёртвый, сигнал возвращается
в барабан на новый круг, и в трассе появляется `круг 2`. Видно при
`--live 26` и `--live 10`; при 30 живых контактах мёртвых нет.
